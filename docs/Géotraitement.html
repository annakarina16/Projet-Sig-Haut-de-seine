Géotraitement

1- Géotraitement Raster

Traitement Raster

Le traitement raster repose sur l’exploitation d’une image NDVI issue du Copernicus Browser, exportée au format GeoTIFF 16 bits. Le fichier contient trois bandes, dont la bande 2 correspond à l’indice de végétation NDVI.

Dans un premier temps, la bande 2 a été extraite puis reprojetée dans le système de coordonnées Lambert 93 (EPSG 2154) afin d’assurer la cohérence spatiale avec les autres couches du projet.

L’image a ensuite été découpée selon l’emprise du département des Hauts-de-Seine, puis masquée pour ne conserver que les pixels situés à l’intérieur des limites communales.

Les valeurs brutes du fichier étant encodées en uint16 (de 0 à 65535), une conversion a été appliquée pour ramener les valeurs dans l’intervalle NDVI standard de -1 à +1, selon la formule suivante :

\[NDVI_{réel} = -\left(\frac{valeur}{65535} \times 2 - 1\right)\]

L’inversion du signe a été nécessaire car les valeurs étaient inversées dans le fichier source, la végétation présentant des valeurs négatives.

Un seuillage a ensuite été appliqué en ne conservant que les pixels dont la valeur NDVI est supérieure à 0,3, correspondant aux zones de végétation significative. Ce masque binaire a enfin été vectorisé en polygones grâce à la fonction terra::as.polygons, permettant de passer du domaine raster au domaine vecteur.

Schéma de géotraitement :

library(sf)
library(terra)
library(mapsf)

img <- terra::rast("NDVIF.tiff")
communes_hds <- sf::st_read("communes.shp", quiet = TRUE)
hds_contour <- sf::st_transform(communes_hds, 2154) |> sf::st_union()
layer_v <- img[[2]]
hds_terra <- terra::vect(hds_contour)

ndvi_hds <- terra::project(layer_v, sf::st_crs(hds_contour)$wkt) |>
            terra::crop(hds_terra) |>
            terra::mask(hds_terra)

ndvi_reel = -((ndvi_hds / 65535) * 2 - 1)

mf_theme("default")
mapsf::mf_raster(x = ndvi_reel, pal = rev(mf_get_pal(n = 10, palette = "RdYlGn")),
                 breaks = "equal", nbreaks = 10, leg_title = "Indice Végétation", leg_val_rnd = 2)
mapsf::mf_map(hds_contour, col = NA, border = "black", lwd = 1.5, add = TRUE)
mf_layout(title = "NDVI découpé sur les Hauts-de-Seine", scale = TRUE, arrow = TRUE)

veg_mask = ndvi_reel > 0.3
veg_mask[veg_mask == 0] = NA
poly_veg_temp = terra::as.polygons(veg_mask, aggregate = TRUE)
poly_veg = sf::st_as_sf(poly_veg_temp)
poly_veg = sf::st_intersection(poly_veg, hds_contour)
mf_theme("default")
mf_map(hds_contour, col = "#f0f0f0", border = "grey")
mf_map(
  x = poly_veg,
  col = "forestgreen",
  border = "darkgreen",
  lwd = 0.5,
  add = TRUE
)
mf_layout(title = "Zones de végétation vectorisées (Seuil > 0.3)", scale = TRUE)

2- Géotraitement vecteur

Traitement Vecteur

Le traitement vecteur s’appuie sur trois couches géographiques : les limites communales des Hauts-de-Seine (communes.shp), les espaces naturels du département (ENF.shp) et les polygones de végétation issus de la vectorisation du raster NDVI.

Dans un premier temps, les couches communes.shp et ENF.shp ont été reprojetées en Lambert 93 (EPSG 2154) afin d’assurer la cohérence des systèmes de coordonnées entre toutes les couches.

Les communes ont ensuite été dissoutes via une union spatiale (st_union) pour constituer le contour global du département, utilisé comme zone d’étude lors du traitement raster.

Deux intersections spatiales ont ensuite été réalisées :

  • Une première intersection entre les polygones de végétation NDVI et les limites communales, permettant de calculer la surface végétalisée pour chaque commune.
  • Une seconde intersection entre les espaces naturels et les limites communales, permettant de calculer la surface d’espaces naturels pour chaque commune.

Ces intersections ont permis de calculer pour chaque commune sa surface totale, sa surface végétalisée et sa surface en espaces naturels, exprimées en hectares, constituant la base des analyses statistiques et cartographiques réalisées par la suite.

Schéma de géotraitement :

Répartition de la végétation et des espaces naturels dans le 92:

library(sf)
library(mapsf)
library(terra)

communes_hds = sf::st_read("communes.shp", quiet = TRUE)
espaces_naturels = sf::st_read("espaces-naturels-sensibles-ens-et-espaces-naturels-associes-ena.shp", quiet = TRUE)
espaces_naturels = sf::st_transform(espaces_naturels, sf::st_crs(communes_hds))

mf_theme("default")
mf_map(communes_hds, col = "#f0f0f0", border = NA)
mf_map(x = poly_veg, col = "lightgreen", border = "lightgreen", add = TRUE)
mf_map(x = espaces_naturels, col = "forestgreen", border = "forestgreen", lwd = 0.5, add = TRUE)
mf_map(communes_hds, col = NA, border = "black", lwd = 1, add = TRUE)
legend(
  "right",
  legend = c("Espaces végétalisés NDVI > 0.3", "Espaces naturels"),
  fill = c("lightgreen", "forestgreen"),
  border = c("lightgreen", "forestgreen"),
  title = "Légende",
  bty = "n"
)
mf_layout(title = "Répartition des espaces naturels du département des Hauts-de-Seine", scale = TRUE, arrow = TRUE)

library(sf)
library(dplyr)

communes_hds = sf::st_transform(communes_hds, 2154)
espaces_naturels = sf::st_transform(espaces_naturels, 2154)
poly_veg_t = sf::st_transform(poly_veg, 2154)

surface_commune = communes_hds |>
  mutate(surface_commune_ha = as.numeric(sf::st_area(geometry)) / 10000)

inter_veg = sf::st_intersection(poly_veg_t, communes_hds) |>
  mutate(surface_veg_ha = as.numeric(sf::st_area(geometry)) / 10000) |>
  sf::st_drop_geometry() |>
  group_by(nom) |>
  summarise(surface_veg_ha = round(sum(surface_veg_ha), 2))

inter_en = sf::st_intersection(espaces_naturels, communes_hds) |>
  mutate(surface_en_ha = as.numeric(sf::st_area(geometry)) / 10000) |>
  sf::st_drop_geometry() |>
  group_by(nom) |>
  summarise(surface_en_ha = round(sum(surface_en_ha), 2))

tableau = surface_commune |>
  sf::st_drop_geometry() |>
  select(nom, surface_commune_ha) |>
  mutate(surface_commune_ha = round(surface_commune_ha, 2)) |>
  left_join(inter_veg, by = "nom") |>
  left_join(inter_en, by = "nom") |>
  mutate(
    surface_veg_ha = ifelse(is.na(surface_veg_ha), 0, surface_veg_ha),
    surface_en_ha = ifelse(is.na(surface_en_ha), 0, surface_en_ha)
  ) |>
  arrange(nom)

colnames(tableau) = c("Commune", "Surface commune (ha)", "Surface végétation (ha)", "Surface espaces naturels (ha)")

knitr::kable(tableau, caption = "Surface végétation et espaces naturels par commune")
