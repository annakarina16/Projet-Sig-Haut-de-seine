Jointures attributaires

Les jointures attributaires ont permis de consolider l’ensemble des données spatiales et statistiques à l’échelle communale.

Dans un premier temps, une jointure entre les deux tableaux CSV a été réalisée. Le fichier tableau1.csv contenant les montants de dépenses par habitant 2024 et le fichier tableau2.csv contenant les revenus médians ont été joints sur les champs INSEE (tableau1) et id (tableau2). Ces deux champs contiennent les codes INSEE des communes et ont été préalablement convertis en caractères afin d’assurer la compatibilité des types entre les deux tables, le champ INSEE étant initialement de type entier et le champ id de type caractère.

Dans un second temps, une jointure entre les surfaces communales et les données socio-économiques a été effectuée sur les champs id (couche communes) et INSEE (tab_joint). Le champ id de la couche communale correspond au code INSEE de chaque commune et a également été converti en caractère pour assurer la compatibilité.

Deux jointures intermédiaires ont également été réalisées entre les surfaces calculées lors du traitement vecteur et la table des surfaces communales, en utilisant le champ nom comme clé de jointure :

  • Jointure entre la surface communale et la surface végétalisée NDVI sur le champ nom
  • Jointure entre ce résultat et la surface des espaces naturels sur le champ nom

Cette jointure finale a permis de rassembler dans un seul tableau les informations suivantes pour chaque commune :

  • La surface totale de la commune en hectares
  • La surface végétalisée issue du NDVI en hectares
  • La surface en espaces naturels en hectares
  • Le montant des dépenses par habitant 2024 en euros
  • Le revenu médian en euros

À partir de ce tableau consolidé, deux indicateurs ont été calculés :

  • Le taux de végétation et le taux d’espaces naturels, exprimés en pourcentage de la surface communale
  • Un indice de richesse composite, calculé selon la formule suivante :

\[\text{Indice de richesse} = \left(\frac{R - R_{min}}{R_{max} - R_{min}} \times 0{,}5 + \frac{D - D_{min}}{D_{max} - D_{min}} \times 0{,}5\right) \times 100\]

Où \(R\) représente le revenu médian et \(D\) le montant des dépenses par habitant, permettant de classer les communes des Hauts-de-Seine selon leur niveau de richesse relative.

library(sf)
library(dplyr)
library(terra)
library(kableExtra)

communes_hds = sf::st_read("communes.shp", quiet = TRUE)
communes_hds = sf::st_transform(communes_hds, 2154)
communes_hds$id = as.character(communes_hds$id)

espaces_naturels = sf::st_read("espaces-naturels-sensibles-ens-et-espaces-naturels-associes-ena.shp", quiet = TRUE)
espaces_naturels = sf::st_transform(espaces_naturels, 2154)

img = terra::rast("NDVIF.tiff")
hds_contour = sf::st_union(communes_hds)
layer_v = img[[2]]
hds_terra = terra::vect(hds_contour)

ndvi_hds = terra::project(layer_v, sf::st_crs(communes_hds)$wkt) |>
           terra::crop(hds_terra) |>
           terra::mask(hds_terra)

ndvi_reel = -((ndvi_hds / 65535) * 2 - 1)

veg_mask = ndvi_reel > 0.3
veg_mask[veg_mask == 0] = NA
poly_veg_temp = terra::as.polygons(veg_mask, aggregate = TRUE)
poly_veg = sf::st_as_sf(poly_veg_temp)
poly_veg = sf::st_transform(poly_veg, 2154)

surface_commune = communes_hds |>
  mutate(surface_commune_ha = as.numeric(sf::st_area(geometry)) / 10000) |>
  sf::st_drop_geometry() |>
  select(nom, id, surface_commune_ha)

inter_veg = sf::st_intersection(poly_veg, communes_hds) |>
  mutate(surface_veg_ha = as.numeric(sf::st_area(geometry)) / 10000) |>
  sf::st_drop_geometry() |>
  group_by(nom) |>
  summarise(surface_veg_ha = round(sum(surface_veg_ha), 2))

inter_en = sf::st_intersection(espaces_naturels, communes_hds) |>
  mutate(surface_en_ha = as.numeric(sf::st_area(geometry)) / 10000) |>
  sf::st_drop_geometry() |>
  group_by(nom) |>
  summarise(surface_en_ha = round(sum(surface_en_ha), 2))

tab1 = read.csv2("tableau1.csv")
tab1$Insee = as.character(tab1$Insee)

tab2 = read.csv2("tableau2.csv")
tab2$id = as.character(tab2$id)

tab_joint = tab1 |>
  left_join(tab2, by = c("Insee" = "id")) |>
  select(Insee, Montant_par_habitant_2024, Revenu_med)

tableau_final = surface_commune |>
  left_join(inter_veg, by = "nom") |>
  left_join(inter_en, by = "nom") |>
  left_join(tab_joint, by = c("id" = "Insee")) |>
  mutate(
    surface_commune_ha = round(surface_commune_ha, 2),
    surface_veg_ha = ifelse(is.na(surface_veg_ha), 0, surface_veg_ha),
    surface_en_ha = ifelse(is.na(surface_en_ha), 0, surface_en_ha)
  ) |>
  select(nom, surface_commune_ha, surface_veg_ha, surface_en_ha, Montant_par_habitant_2024, Revenu_med) |>
  arrange(nom)
